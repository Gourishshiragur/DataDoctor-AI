# Databricks Notebooks

Drop exported `.py`/`.ipynb` notebooks here that mirror the Bronze/Silver/Gold logic in
`pipeline/` for use as native Databricks Jobs in Enterprise Mode. A starter notebook,
`bronze_silver_gold_job.py`, is included as a Databricks-native equivalent of the local
pipeline for teams that want the transformation to run inside the workspace rather than
being driven from the Streamlit app.
